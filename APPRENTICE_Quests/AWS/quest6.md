# AWS について説明できる

## 1. AWS とは

AWS とは何か、プログラミング初心者にわかるように説明してください。
Amazon Web Serviceの略

Amazon社が提供するクラウドコンピューティングサービス

- サービスが豊富
- 高負荷に耐えられる、信頼性の高いシステムを少ない手まで運用できる
- リソースが柔軟
- 従量課金


## 2. クラウドとは

クラウドとは何か、プログラミング初心者にわかるように説明してください。

クラウドコンピューティング
物理サーバーを持つオンプレミスと違い仮想サーバーを借りてサービスを運営していく

  - インフラをネットワークで経由して使用、管理すること
  - 利点：初期コストが少ない、すぐに始められること、サーバーの増減が自由に出来ること
  - 欠点：費用の予測がつきづらいこと、クラウド全体で障害が起こると対応のしようがないこと
