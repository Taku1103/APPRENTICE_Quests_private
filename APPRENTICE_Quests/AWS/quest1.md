# HTTP について説明できる

## 1. HTTP とは

HTTP とは何か、プログラミング初心者にわかるように説明してください。

Hyper Text Transfer Protocol
ステートレスなプロトコルでウェブページのファイルをやり取りする通信プロトコルのこと
WebサーバとWebブラウザの間で、Web情報をやりとりするためのプロトコル


## 2. プロトコルとは

HTTP はプロトコルの一種です。プロトコルとは何か、プログラミング初心者にわかるように説明してください。

通信規則のこと

## 3. HTTP リクエスト

HTTP リクエストとは何か、プログラミング初心者にわかるように説明してください。その際に、以下も合わせて説明してください。

- HTTP リクエストはリクエストライン、ヘッダ、メッセージボディの3つの要素から構成されています。それぞれの要素についても説明してください
- HTTP メソッドとは何か、また各メソッドにはどのような意味があるか説明してください


- HTTPリクエスト
クライアントがサーバー側にデータを要求すること

「リクエストライン」
「リクエストヘッダー」
（空行【CR＋LF】）
「メッセージボディ」

- リクエストライン
どういうリクエストかザックリ書かれてるところ
何をどうしたいのか
HTTPメソッド、URI HTTPバージョン
がかかれている

- リクエストヘッダー
クライアントからサーバーに要求するあれこれがかかれている
【フィールド名】：【内容】

- リクエストメッセージボディ
POSTの場合はここにパラメータの値
GETの場合は何も書かれない

- HTTPメソッド
そのURIにどういう操作がしたいのか
URIとHTTPメソッドの組み合わせでサーバー側がどういう操作をしたいのか判別する
GET、POSTが基本
PUT、DELETEなどがある

GET
データの取得
POST
データの新規作成
PUT
データの更新
PATCH
データの一部更新
DELETE
データの削除
HEAD
ヘッダの情報だけ取得

## 4. HTTP レスポンス

HTTP レスポンスとは何か、プログラミング初心者にわかるように説明してください。その際に、以下も合わせて説明してください。

- HTTP レスポンスはステータスライン、ヘッダ、メッセージボディの3つの要素から構成されています。それぞれの要素についても説明してください
- HTTP ステータスコードとは何かを説明してください。また、代表的なステータスコードである200, 201, 204, 301, 400, 401, 403, 404, 500 について説明してください

- HTTPレスポンス
クライアントのHTTPリクエストに対するサーバー側のデータの返答

形式は
「ステータスライン」
「ヘッダ」
（空行【CR＋LF】）
「レスポンスボディ」

- ステータスライン
HTTPリクエストの結果が大まかに書かれている
HTTPのver、ステータスコード、ステータスコードの説明
の順に書かれている

- ステータスコード
100番台：Informational（情報レスポンス）　情報だよ～　
クライアントからのリクエストを受け入れ可能で、継続して処理されている状態
200番台： Success（成功レスポンス）　上手くいったよ～
クライアントからリクエストがサーバに送られ理解されて受理された状態
300番台：Redirection（リダイレクション）　転送したら、こんなんなったよ～
リクエストを完了させるために追加的な処理が必要
400番台：Client Error（クライアントエラー）　おまえ（Webブラウザ側）が、なんかおかしいよ
500番台：Server Error（サーバエラー）　ごめん、俺（Webサーバ側）が、なんかおかしいんだわ

200:ok リクエスト成功
201:Createdリクエストが成功してリソースの作成が完了
204:No Content リクエストに対して送信するコンテンツは無いがヘッダは有用である
DELETEしたときとか
301 Moved Permanently リクエストされたリソースのURLが永遠に変更された
レスポンスで新しいURLが与えられる
恒久的に移動する
400 Bad Request 一般的なクライアントエラー
401 Unauthorized アクセス権が無い、または認証に失敗
403 Forbidden 閲覧権限が無いファイルやフォルダ
404 Not Found Webページが見つからない
422 Unprocessable Entity WebDAVの拡張ステータスコード
リクエストは適正だが意味が異なるためサーバが返すことが出来ない
500 Internal Server Error 何らかのサーバ内で起きたエラー

- ヘッダー
より詳しいレスポンスの必要な情報
【フィールド名】:【内容】で書かれている

- メッセージボディ
相手が欲しがっていた情報のファイルの中身が書かれている
