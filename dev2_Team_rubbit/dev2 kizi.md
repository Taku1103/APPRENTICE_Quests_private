# 課題定義
- 与えられたプロダクトテーマ『ワクワクするもの』
- ゲーマー4人が集まったのもあり、ワクワクをゲーム関連で探すことに
- ゲーム配信サイトTwitchでクリップ周りのシステムが不便なのでそれを自分たちが解消する
- クリップ文化で配信のハイライトを切り抜く文化
- それらをマイリストでまとめて綺麗に整理出来ていない
- 各々がYoutubeで切り抜きとして集めるか、使い勝手の悪い配信者のクリップページから見るしかない
- 今はやりのストグラのように配信者が大人数でわちゃわちゃ集まって面白いイベントが起こったときに色んな視点でみたい、時系列でみたい、などで見れることが少ない。
- 潜在的需要は結構あると踏んだ
- 似たようなTwitchのclipを見るサイトはあるがプレイリストでまとめたりそれを共有したり管理しやすいシステムはない

# 作成プロダクト

List it Bro! for Twitch

配信界隈、特に英語圏では盛り上がる瞬間(スーパープレイをした時など)にclip it, clip it ,bro !!!と言う文化があり、それをもじりました。
